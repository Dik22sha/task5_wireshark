Steps Performed

Opened Wireshark and selected the active network interface (eth0).

Started live packet capture for around one minute.

Generated traffic by browsing websites and using ping google.com.

Stopped capture and saved the file as traffic_capture.pcap.

Applied filters (tcp, http, icmp) to analyze protocol activity.

Exported filtered packets and summarized observations.

Protocols Identified

TCP: Reliable transport layer protocol used for establishing and maintaining connections.

HTTP: Application layer protocol for web communication and data exchange.

ICMP: Network layer protocol used for ping requests and responses.
